### 3. 프록시 / VPN

#### 옵션 A — NordVPN (현재 검토 중)
| 항목 | 월 비용 |
|------|:-------:|
| 연간 구독 기준 (약 $3~4/월) | **$3 ~ $4** |
| 별도 월 구독 시 | **$13** |

- **장점**: 비용 저렴, 이미 구독 예정이라면 추가 비용 없음
- **단점**: 인스타그램이 데이터센터/공유 IP를 차단할 경우 스크래핑 실패 가능
- **테스트 필수**: 실제 인스타 요청이 통과되는지 먼저 확인 후 도입

#### 옵션 B — Residential 프록시 (Smartproxy / DataImpulse 등)
| 사용량 | 월 비용 |
|--------|:-------:|
| 5GB 이하 | **$5** |
| 10GB 이하 | **$10** |
| 5GB 초과분 | 1GB당 $1 |

- 주거용(Residential) IP → 인스타 차단 우회에 유리
- 이미지·영상 로딩 비활성화 시 **5GB 이하로 충분할 가능성 높음** (테스트 필요)

## 단계별 도입 제안

| 단계 | 구성 | 예상 비용 |
|------|------|:--------:|
| 1단계 (테스트) | Lightsail 1대 + NordVPN | ~$24/월 |
| 2단계 (안정화) | Lightsail 1대 + Residential 프록시 5GB | ~$29/월 |
| 3단계 (확장) | Lightsail 2대 + 프록시 | ~$53/월 |

- **NordVPN으로 인스타 스크래핑이 안정적으로 동작하면** → 그대로 운영
- **차단/제한이 자주 걸리면** → Residential 프록시로 전환

## 리스크 요인

1. **NordVPN 차단**: 인스타그램이 공유 VPN IP를 막을 경우 → Residential 전환 비용 발생
2. **트래픽 초과**: 프록시 5GB 초과 시 GB당 $1 추가
3. **Vercel DB 연결**: DB 쿼리가 많아질 경우 Vercel serverless 함수의 연결 풀 이슈 가능
4. **Linux Stealth**: 현재 macOS 기준 코드 → 리눅스 헤드리스 환경에서 추가 우회 설정 필요
