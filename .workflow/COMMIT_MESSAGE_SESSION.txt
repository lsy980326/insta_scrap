### 주요 변경사항

#### 세션 관리 통합
- 추적 모듈에 SessionManager 통합
  - 저장된 세션(쿠키 + User-Agent) 로드 및 재사용
  - 세션 검증 후 유효하면 로그인 생략
  - 로그인 성공 후 세션 자동 저장
  - 스크래퍼와 동일한 세션 관리 방식 적용

#### 통계 추출 개선
- 조회수뿐 아니라 좋아요, 댓글 수도 함께 추출
  - HTML 구조 기반 정확한 추출 (`div._aaj-`, `div._aaj_` 활용)
  - 첫 번째 `li`: 좋아요 수
  - 두 번째 `li`: 댓글 수
  - 조회수 아이콘 옆: 조회수
- 스크롤 횟수 증가 (3회 → 5회)
  - 더 많은 릴스를 확인하여 추출 성공률 향상

#### 로그 개선
- 개별 릴스 로그에 좋아요, 댓글, 조회수 모두 표시
  - 예: `릴스 ID 'xxx' - 좋아요: 36000, 댓글: 544, 조회수: 445.4만`
- 크리에이터별 요약 로그 추가
  - 각 크리에이터 처리 후 추출된 통계 요약 표시

#### 데이터베이스 저장 개선
- 좋아요, 댓글도 DB에 저장
  - `reel_metrics` 테이블에 시계열 데이터로 저장
  - 조회수, 좋아요, 댓글 수 모두 추적 가능

#### 성능 최적화
- 페이지 로드 대기 시간 단축 (3초 + 1-2초 → 1초 + 0.5-1초)
- 스크롤 후 대기 시간 단축 (2초 + 1-2초 → 1초 + 0.5-1초)
- 크리에이터 간 딜레이 단축 (2-4초 → 1-2초)
- 네트워크 대기 최적화 (networkidle → domcontentloaded, 5초 → 3초)
- 전체 실행 시간 약 30-40% 단축 예상
